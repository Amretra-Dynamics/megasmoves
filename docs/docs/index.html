Megas Moves documentation

One local operator

MegasMoves.exe is the complete Windows product: native console, local runtime and embedded Megas MCP. People and agents use the same capability core. The marketing website does not operate your computer.

Actions and tasks

Create and edit multiple Actions with folder references, file references and tasks. Selecting a path records shared context; it does not start services. Chitraagni workspaces, projects and products remain in the authorized integration.

Readiness and evidence

Inspect supported agents, selected services, ports, bounded logs, connected devices and recorded operations. Start only the selected service slice. Confirm the observed outcome before marking work complete.

Availability

Development downloads include Windows, Android and a bundled Linux command-line build. macOS command-line builds are listed by architecture on Downloads. The public ChatGPT plugin is coming soon.
