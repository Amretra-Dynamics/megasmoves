Getting started

Choose a build

Open Downloads and check platform, version, code revision date, build date, size and SHA-256. The Windows installer includes the complete app and the megas terminal launcher.

Install with Python

The package command is pip install megasmoves on Windows, macOS and Linux with Python 3.11 or later. It provides the megas launcher. On Windows the first run installs the native app if needed, then uses that same installation. Use the direct package command on Downloads while PyPI publication is pending.

Install from our domain

Use the Python-package command on Downloads to install directly from megasmoves.io. It does not require Git or a PyPI listing. Native Windows and macOS/Linux commands use megasmoves.io/install.ps1 and megasmoves.io/install.sh. The scripts verify each download before installation.

Install without Python

Select your operating system under Without Python on Downloads. Windows uses PowerShell to verify and run the app installer. macOS and Linux use the bundled native runtime with curl and system checksum tools. macOS architecture and release version must match your device. Account credentials and saved work are preserved.

Update in place

Install over the existing MegasMoves installation and preserve credentials and saved data. Avoid running an old installed copy alongside a repository build. Unsigned development builds are not signed production updates.

Sign in locally

Use the existing Firebase account flow inside the application. The marketing website is not a prerequisite for local operation. Never put passwords or access tokens in agent prompts.

Choose work

Create an Action, select its folder and file references, and add tasks. This is the shared registry visible to people and agents. Saving an Action does not execute it.

Inspect and connect

Check readiness, ports, logs and devices. Use the application embedded MCP setup and verify a real tool call against the installed operator. Private testing is separate from public ChatGPT publication.
