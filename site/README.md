# Website release staging

The files in this directory are a dependency-free, static promotional landing page. They are intentionally **not deployed** by this private repository.

Publication steps for the organization owner:
1. Verify all feature and plan claims against real product behavior.
2. Approve the release commit and make the repository public.
3. Publish this directory through a reviewed GitHub Pages workflow or to the verified megasmoves.io domain.
4. Configure DNS, HTTPS, canonical URL, privacy policy, support address, and analytics consent if analytics is later added.
5. Confirm the GitHub link works from an incognito browser before public video/X announcements.

The planned $20/month Megas WoW offering has **no checkout** in this preview; it is marked as not yet purchasable. The page has no trackers, third-party scripts, or remote assets.
