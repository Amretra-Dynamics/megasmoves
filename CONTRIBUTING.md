# Contributing

MegasMoves Community welcomes reviewed, testable improvements when it opens publicly.

1. Describe the change and trust-boundary implications in an issue.
2. Use a focused branch and explain the source provenance.
3. Add tests, including negative permission tests when relevant.
4. Run python -m unittest discover -s tests -v and compileall.
5. Submit a pull request for review.

Do not add arbitrary shell execution, silent folder approval, hidden network access, internal production endpoints, credentials, private user data or unlicensed third-party material.

Disclose vulnerabilities privately as described in SECURITY.md. Contributions to this repository are accepted under MIT unless otherwise documented.
